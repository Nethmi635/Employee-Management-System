Help & FAQ

Common Tasks

  • Employees: Go to Employees → Add Employee to create a profile.
  • Attendance: Open Attendance → Check-In/Out or edit rows.
  • Leave: Open Leave → submit a new request; managers update status.
  • Performance: Open Performance → add quarterly/annual reviews.
  • Shifts: Open Shifts (manager) → add day/night, edit, or swap.
  • Notifications: Open Notifications → mark read or delete.
  • Exports: Attendance/Performance pages → Export CSV.
